# Credits

Opaline is built on open-source work, and the copyright notices of the files it inherited are kept
in place. See [`NOTICE`](https://github.com/a1b2d56/opaline/blob/main/NOTICE) for the full list of
changes.

- **[Miuix](https://github.com/compose-miuix-ui/miuix)** by YuKongA and the compose-miuix-ui
  contributors (Apache-2.0). The component library, theme system, blur, shader, squircle,
  navigation and icon modules, the example app and this documentation site all started there.
- **[COUI](https://github.com/suqi8/coui)** by suqi8 and contributors (Apache-2.0). A fork of Miuix
  that rethemed it to ColorOS 16 and added Chip, CodeTextField, the date and time pickers,
  InputView, Stepper, TopTips, FullPageStatement, the loading and security dialogs and more.
- **AndroidX Navigation 3** by The Android Open Source Project (Apache-2.0). Parts of
  `opaline-navigation3-ui` are adapted from it.

Upstream Miuix fixes are still taken as reviewed patches; the log is
[`docs/upstream-sync.md`](https://github.com/a1b2d56/opaline/blob/main/docs/upstream-sync.md).
